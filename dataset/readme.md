Información de c/u de los campos en el archivo :
1 ID : ID del cliente / ID : Идентификатор клиента
2 Age : Edad del cliente / Возраст: Возраст клиента
3 Experience : #años de experiencia / Опыт : #лет опыта
4 Income : Ingreso anual de cliente ($000) / Доход : Годовой доход клиента (000 долларов США)
5 ZIP Code : Código ZIP de casa / Почтовый индекс : Домашний почтовый индекс
6 Family : Número de miembros familiares / Семья : Количество членов семьи
7 CCAvg : Promedio de Gasto en Tarjetas de crédito por mes ($000) / CCAvg : Средние расходы по кредитным картам в месяц (000 долларов США)
8 Education : Nivel de Educación. 1: No graduado; 2: Graduado; 3: Profesional / Образование : Уровень образования. 1: Не окончил; 2: Выпускник; 3: Профессиональный
9 Mortgage : Valor de hipoteca, si existiera. ($000) / Ипотека : Стоимость ипотеки, если она существовала. (000 долларов США)
10.Personal Loan : Aceptó el cliente el crédito personal ofrecido en la última campaña? / Личный заем : Принял ли клиент личный заем, предложенный в последней кампании?
11.Securities Account : El cliente tiene una cuenta con activos financieros con el banco? / Счет ценных бумаг : Есть ли у клиента счет с финансовыми активами в банке?
12.CD Account : El cliente tiene una cuenta certificada de deposito(CD) con el banco? / CD Учетная запись: У клиента есть сертифицированный депозитный счет (CD) в банке?
13.Online : El cliente usa medios de banca por internet? / Онлайн : Использует ли клиент средства интернет-банкинга?
14.Credit card : El cliente usa tarjeta de crédito manejada por algún otro banco? / Кредитная карта: Клиент пользуется кредитной картой, обслуживаемой каким-либо другим банком?
